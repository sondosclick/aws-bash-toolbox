# Security Policy

## Supported versions

This project is in **alpha**. Only the latest commit on `main` and the most recent tag (if any) are supported.

## Reporting a vulnerability

Please do **not** open public issues for security reports.

Preferred:
- Use GitHub Security Advisories (Security tab -> "Report a vulnerability").

If advisories are not available:
- Contact the maintainer via GitHub: @sondosclick

We aim to respond within 7 days.
